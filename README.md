# ☕️ JBang conference ♯❗️

## 🧑‍💻 How to use / contribute 🐳

The simplest way to use this code is to re-open the project with the Dev Containers.

## 🎙️ Talk steps

  - create a typical maven project: [00-create-maven-project.sh](bin/00-create-maven-project.sh)
  - run [01-Mvn-App-Run.sh](bin/01-Mvn-App-Run.sh)
  - install JBang [02-jbang-installation.sh](bin/02-jbang-installation.sh)
  - run App with JBang [03-jbang-app.sh](bin/03-jbang-app.sh)
  - add shebang in APP (`04-add-shebang-app`)
  - run App as a script [05-jbang-app-shebang.sh](bin/05-jbang-app-shebang.sh)
  - run AppLSF: launch single file [06-lsf-app-shebang.sh](bin/06-lsf-app-shebang.sh)
  - create [Jarvis.java](./jbang-demo/Jarvis.java)
    - add Jarvis dependencies (`07-add-jarvis-deps`)
    - add external resources (`08-add-external-resources`)
    - add AI Services mode (`09-ai-services-mode`)
    - configure Mistral model (`10-mistral-model`)
    - add memory (`11-add-memory`)
    - create assistant (`12-create-assistant`)
    - add a prompt (`13-prompt`)
    - test Jarvis [14-jbang-jarvis.sh](bin/14-jbang-jarvis.sh)
  - install script in path [15-install-jarvis.sh](bin/15-install-jarvis.sh)
  - run from anywhere Jarvis [16-run-jarvis.sh](bin/16-run-jarvis.sh)
  - run from URL Jarvis [17-run-jarvis-from-gh.sh](bin/17-run-jarvis-from-gh.sh)
  - creating and using alias [18-run-jarvis-from-alias.sh](bin/18-run-jarvis-from-alias.sh)
  - use a remote catalogue [19-run-from-remote-catalogue.sh](./19-run-from-remote-catalogue.sh)
  - install `httpd` alias [20-install-httpd.sh](bin/20-install-httpd.sh)
  - create local catalog [21-create-catalog.sh](bin/21-create-catalog.sh)
  - add remote catalog [22-add-remote-catalog.sh](bin/22-add-remote-catalog.sh)
  - install `jarvis-catalog` app [23-install-jarvis-catalog-app.sh](bin/23-install-jarvis-catalog-app.sh)
  - create script [JarvisPreview.java](./jbang-demo/JarvisPreview.java)
  - activate preview for Java 21 (`24-enable-java-preview` && `25-use-sysout`) 
  - run [26-jbang-jarvis-unnamed.sh](bin/26-jbang-jarvis-unnamed.sh)
