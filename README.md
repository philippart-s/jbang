## 🧑‍💻 How to use / contribute 🐳

The simplest way to use this code is to re-open the project with the Dev Containers.

## 🎙️ Talk steps

  - create a typical maven project: [00-create-maven-project.sh](./00-create-maven-project.sh)
  - run [01-Mvn-App-Run.sh](./maven-demo-create/01-Mvn-App-Run.sh)
  - create Jarvis app: [Jarvis](./maven-demo/src/main/java/fr/wilda/Jarvis.java)
    - add AI Services mode (`02-ai-services-mode`)
    - configure Mistral model (`03-mistral-model`)
    - add memory (`04-add-memory`)
    - create assistant (`05-create-assistant`)
    - add a prompt (`06-prompt`)
    - test Jarvis [07-run-jarvis-mvn.sh](./maven-demo/07-run-jarvis-mvn.sh)
  - install JBang [08-jbang-installation.sh](./08-jbang-installation.sh)
  - add shebang in APP (`09-add-shebang-app`)
  - run App with JBang [10-jbang-app-shebang.sh](./jbang-demo/10-jbang-app-shebang.sh)
  - create [Jarvis.java](./jbang-demo/Jarvis.java)
    - add Jarvis dependencies (`11-add-jarvis-deps`)
    - add external resources (`12-add-external-resources`)
    - test Jarvis [13-jbang-jarvis.sh](./jbang-demo/13-jbang-jarvis.sh)
